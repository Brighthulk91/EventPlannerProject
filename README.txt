Event Planner - README

1. Copy all files to C:\xampp\htdocs\event-planner
2. Create folder uploads inside event-planner and ensure writable.
3. Place public images in public/images (logo/banner).
4. Import db.sql into MySQL (phpMyAdmin).
5. Edit config.php DB credentials if needed.
6. Start Apache & MySQL (XAMPP). Open http://localhost/event-planner/
7. Use Register to create Manager and Guest accounts.
8. Manager: Create events, send invitations, upload gallery.
9. Guest: Search events, book and pay (simulated).
